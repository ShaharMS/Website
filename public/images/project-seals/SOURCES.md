# Project seal sources

- `blustone.svg`: approved mint shield design, using the unchanged project icon embedded from https://avatars.githubusercontent.com/u/177238634?v=4 (The Blustone Revival Project GitHub organization avatar). Established date: 1 August 2024, confirmed by the project owner. The date is rendered as editable HTML in the homepage rather than baked into the SVG.

- `ezworksheet.svg`: approved first EZWorksheet study, a pale organic document impression. The document symbol is from `ShaharMS/EZWorksheet/assets/images/preIcon.svg`; the monochrome treatment follows the original icon and app UI. The editable HTML date is `EST. 03.10.2021`.
- `dynamically.svg`: approved first Dynamically study, triangular black wax with recessed geometry. Black, white and royal blue follow `ShaharMS/Dynamically-CS/Design/UIColors.cs`. The editable HTML date is `EST. 03.07.2023`.
- `texter.svg`: approved purple ink-drop impression. Purple `#5959AC` and orange `#E48931` derive from the existing Texter documentation styles. The editable HTML date is `EST. 06.02.2022`.

The three new designs were selected from the organic pressed-wax canvas on
2026-10-25. Their date values use repository creation dates, with the owner-requested
`EST.` label; dates, names, descriptions and link text remain editable in the local
website editor. The exported SVGs omit embedded dates and experimental wear layers.

## Current wall designs — 25 October 2026

The current EZWorksheet, Dynamically, and Texter assets replace the earlier organic studies above. EZWorksheet uses the original embedded `preIcon.svg` paths in a yellow folded-document impression. Dynamically uses an orange quadrilateral with a light face and exact circumcircle/right-triangle/incircle geometry; the circumcenter lies on the incircle. Texter uses compact Latin/Hebrew lettering in a purple impression. Dates remain editable HTML, positioned inside dedicated clear bands by `project-seals.css`. No date is baked into an asset. Texter and Dynamically have larger resting and expanded sizes.
