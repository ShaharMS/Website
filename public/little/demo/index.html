Variables and output

        
define x = 3
x = x + 3
print(x)

        
This prints 6. Use define to declare a variable and print to write output.

        
Actions

        
action getNumber() = {
    return 5
}
print(getNumber())

        
Use action to declare a function and return to return its result.

        
Loops

        
define i = 0
while (i <= 10) {
    print(i)
    i = i + 2
}

        
Language reference

        
as specifies a type, nothing is the null value, and true and false are boolean values. Built-in types include Number, Decimal, Boolean, and Characters.
