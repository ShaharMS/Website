# Icon sources

These SVGs were downloaded from the web, then adapted to the existing icon pattern.
No image generator was used. The added artwork uses the existing monochrome palette.

- Shirt: https://github.com/tabler/tabler-icons/blob/main/icons/outline/shirt.svg
- Clothes hanger: https://github.com/tabler/tabler-icons/blob/main/icons/outline/hanger.svg
- Car: https://github.com/tabler/tabler-icons/blob/main/icons/outline/car.svg
- Steering wheel: https://github.com/tabler/tabler-icons/blob/main/icons/outline/steering-wheel.svg
- Milk bottle: https://github.com/tabler/tabler-icons/blob/main/icons/outline/milk.svg
- Chocolate-bar label: https://github.com/tabler/tabler-icons/blob/main/icons/outline/chocolate.svg
