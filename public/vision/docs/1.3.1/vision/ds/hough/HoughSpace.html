The Hough space is a 2D array of Int. The accumulator is that array.

read onlyimage:Image

This isn't really the accumulator, but it is used to visualize the Hough space. the reason this and the accumulator are separate is because the accumulator's value is more "predictable" - represented as Int and not colors.

maximums:Array<IntPoint2D>

The "maximums" of the Hough space:

when a certain point in the accumulator is greater than a given value, the point is considered a maximum, and the value is added to the maximums array.

rays:Array<Ray2D>

The rays detected from the accumulator.

Those are defined only when using the ~~getHoughSpaceWithRays~~ method.
