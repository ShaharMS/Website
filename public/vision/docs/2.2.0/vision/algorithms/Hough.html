class Hough

package vision.algorithms

@:directlyUsed@:allow(tests.HoughStandardTest)@:allow(tests.HoughProbabilisticTest)

Hough feature detection for lines and circles.

This class only performs feature extraction. Visualization belongs in Vision or caller code.

Three transforms live here:

  1. Standard line Hough — edge pixels vote in (rho, theta) space; peaks become Ray2D lines.
  2. Probabilistic line Hough — reuses standard candidates, then extracts bounded Line2D segments from supported edge runs along each candidate.
  3. Circle Hough — votes for circle centers and radii from Canny edges and returns Circle2D geometry.

Application wrappers: Vision.houghLineSegmentDetection(...), Vision.houghCircleDetection(...).

Static methods

staticcreateAccumulator(thetaBins:Int, rhoBins:Int):Matrix2D

Allocates a (theta, rho) vote accumulator filled with zeroes.

staticdetectCircles(image:Image, ?options:HoughCircleOptions):Array<Circle2D>

Detects circles with a gradient-guided center accumulator.

Input is grayscaled, optionally median-filtered, edge-detected, then searched over the configured radius range. Accumulator votes stay internal; only Circle2D geometry is returned.

staticdetectLineSegments(image:Image, ?options:ProbabilisticHoughLineOptions, ?edgeImage:Image):Array<Line2D>

Detects bounded line segments with probabilistic Hough.

Standard (rho, theta) candidates are found first, then each candidate is walked along the edge image to extract supported pixel runs as segments.

edgeImage must match image dimensions when provided, because segment endpoints are bounded to that canvas.

staticdetectLines(image:Image, ?options:HoughLineOptions):Array<Ray2D>

Detects full lines using the standard Hough transform.

Edge pixels vote into (rho, theta) bins. Peaks above voteThreshold become Ray2D values that can be clipped with Ray2D.toLine2D(...).

staticdetectLinesFromPoints(points:Array<Point2D>, width:Int, height:Int, ?options:HoughLineOptions):Array<Ray2D>

Same accumulator path as detectLines(...), but votes from explicit (x, y) points.
