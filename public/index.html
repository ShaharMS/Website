Little

Little is a programming language I made, and it's goal is to teach children how to program, in an easy and accessible way.

You can write it's source code in whatever language you'd like to write in - english, spanish, hebrew or arabic - and you'd still be able to run it :)

On the (25th April, 2023), The language's initial development was finished, and it supported pretty much everything any programming language support, even with some extra features on top

Since then, it was used as a school project, and thus vastly improved and expanded - supporting many more modern features, and being much more "interfacable" for both app developers that wish to use DSLs in their apps, and general users of the language (if they actually exist :) )

Vision

Vision is an open-source, cross framework and cross-platform computer vision & image manipulation library for haxe.

When i started development on EZWorksheet, I realized there wasn't any computer vision library, on haxelib or github even. At the time it did kinda interest me, so i wondered i should give learning computer vision & image manipulation a shot, and, well, after learning a bunch of math an algorithms, that worked!
