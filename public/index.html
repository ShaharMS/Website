Little

Little is a programming language I made, with the goal of teaching children how to program, in an easy and accessible way.

You can write it's source code in whatever language you'd like to write in - English, Spanish, Hebrew or Arabic - and you'd still be able to run it :)

On 25th April, 2023, The language's initial development was finished, and it supported pretty much everything any programming language support, with some extra features on top

Since then, it was used as a school project, and thus vastly improved and expanded - supporting many more modern features, and being much more friendly for both app developers that wish to use DSLs in their apps, and general users of the language (if they even exist😅)

C

A compiled systems language with direct control over memory and hardware. Commonly used for operating systems, embedded software, libraries, and native interfaces.

Rust

A systems language that combines native performance with memory safety, checked by the compiler. Its ownership model makes resource lifetimes explicit.

Java

A general-purpose language that runs on the Java Virtual Machine. Its libraries and tooling are used for servers, applications, and game plugins.

C#

A typed, general-purpose language in the .NET ecosystem. It is used for desktop applications, web services, tools, and games.

Haxe

A typed language and cross-compiler. One Haxe codebase can target platforms such as JavaScript, C++, Java, and C#, with platform-specific escape hatches.

Python

A general-purpose language with a readable syntax and a large library ecosystem. A useful companion for automation, experiments, data work, and tooling.

JavaScript

The programming language of the web. It powers browser interactions and also runs outside the browser through runtimes such as Node.js.

TypeScript

JavaScript with a static type system. The types help catch mistakes and describe interfaces; the output still runs as ordinary JavaScript.

HTML

The structural language of web pages. Elements describe the meaning of content, from headings and links to forms, images, and interactive controls.

CSS

The language that styles and lays out the web. It controls typography, color, responsive layouts, animation, and how a page adapts to different screens.

React

A library for building interfaces from components. State and data determine what appears on screen, while components keep pieces of an interface reusable.

Node.js

A runtime for JavaScript outside the browser. It is widely used for servers, command-line tools, build systems, and network applications.

.NET

A development platform with a managed runtime, standard libraries, and tooling. Languages such as C# use it to build applications across platforms.

Vite

A frontend development server and build tool. It gives web projects a fast feedback loop during development and packages their assets for release.

SQLite

An embedded SQL database that lives in a regular file. Applications can store and query structured data without running a separate database server.

Tailwind CSS

A utility-first CSS framework. Small styling classes compose directly in markup to build custom layouts and visual systems.

HaxeFlixel

A 2D game framework built with Haxe and OpenFL. It provides practical game-building pieces such as sprites, animation, collision, input, and tilemaps.

Avalonia

A cross-platform UI framework for .NET. Interfaces are described with XAML and code, and can share a common application across desktop platforms.

Lime

A foundational layer for Haxe applications. It supplies platform access for windows, input, audio, graphics contexts, and other native capabilities.

OpenFL

A Haxe framework for cross-platform graphics and applications. Its Flash-style APIs cover drawing, display objects, audio, input, and assets.

OpenShift

An application platform built around Kubernetes. It brings together tools for deploying, operating, and managing containerized applications.

Kotlin

A typed language created by JetBrains. It works with Java on the JVM and also supports shared code across platforms through Kotlin Multiplatform.

MongoDB

A document database that stores flexible, JSON-like records in BSON. Applications can query, index, and aggregate those documents without a fixed table layout.

HaxeUI

A cross-platform UI toolkit for Haxe. It provides reusable interface components, layouts, styling, and multiple rendering backends.

WPF

Windows Presentation Foundation is a .NET framework for Windows desktop interfaces. XAML, data binding, layout, and vector graphics help build rich applications.

Flash

Adobe Flash combined vector graphics, animation, audio, and ActionScript for interactive media and games. Its display-list model influenced frameworks such as OpenFL.
